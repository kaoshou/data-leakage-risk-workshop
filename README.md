# 資料外洩安全防護工作坊

提供課堂分組使用的單頁工作坊，共有 12 個企業資料外洩情境。每題包含學習目標、已知事實、中小企業現實難題、現有可用資源、角色分工、三項任務、事件轉折，以及可自動保存的討論與報告紀錄。

## 課堂使用

1. 直接以瀏覽器開啟 `index.html`，不需安裝套件或連線到伺服器。
2. 輸入小組名稱，以類型、難度或關鍵字選題，也可使用隨機抽題。
3. 開啟情境後啟動 20 分鐘計時；剩餘約 8 分鐘時揭露事件轉折。
4. 小組先以現有人力、工具與流程提出不新增採購的 7 天方案，再規劃 30／90 天投資條件。
5. 在頁面中完成風險、前 24 小時行動、優先改善與 7／30／90 天計畫。
6. 使用複製、下載或列印功能整理 5 分鐘報告。

討論內容會依「小組名稱＋情境」分開保存在目前瀏覽器，也可以由小組自行清除。請勿輸入真實個資或公司機密。

教師可使用 `index.html?scenario=8&group=第3組` 形式的網址，預先指定小組名稱與情境編號。
